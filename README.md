# Talent Engine — Prototype web

## Lancer l'application
1. Téléchargez et décompressez `Talent_Engine.zip`.
2. Ouvrez `index.html` dans un navigateur moderne (Chrome, Firefox, Edge).
3. Cliquez sur **Charger la démonstration** pour tester avec des candidatures fictives.
4. Utilisez **Nouvelle candidature** pour ajouter un profil réel ou de test.
5. Depuis Candidatures, filtrez les profils et cliquez sur **Exporter CSV** pour exporter les données.

## Fonctionnalités
- Tableau de bord avec statistiques.
- Formulaire de candidature.
- Barème transparent sur 100 points.
- Classement et filtres.
- Fiche détaillée et justification du score.
- Export CSV.
- Stockage local du navigateur (`localStorage`).

## Limites importantes
Ceci est un prototype de démonstration côté navigateur. Les données sont stockées uniquement dans le navigateur de l'appareil et ne sont pas envoyées à un recruteur. Elles peuvent être perdues si le stockage du navigateur est effacé. Ne l'utilisez pas pour gérer de vraies candidatures sensibles avant d'avoir ajouté un serveur, une base de données, une authentification, des sauvegardes et des contrôles d'accès. Les scores doivent rester une aide à la décision et être vérifiés par un humain.
